# Apple AirPods Pro (2. Generation) – Interaktives Web-Erlebnis

Ein hochperformantes, haptisches und animiertes Apple-Showcase für die **AirPods Pro (2. Generation) mit MagSafe Ladecase (USB-C)**.

## ✨ Highlights & Features

- **Fotorealistischer 3D-Tilt Hero:** Hochauflösende Studio-Renderings der AirPods Pro mit Maus-gesteuertem 3D-Perspektiven-Tilt, Specular-Highlights und konzentrischen 3D-Akustikwellen.
- **Nahtlose zweistufige Scroll-Bühne:** Pinned Transition vom Stereo-AirPod-Paar zur explodierten H2-Treiberarchitektur mit Callout-Badges ohne Scroll-Löcher.
- **Interaktiver Vorher/Nachher ANC Wipe-Slider:** Schiebebühne zum Vergleichen von ungefiltertem Straßenlärm (+84 dB) und absoluter Ruhe (-42 dB Rauschdämpfung) mit Web Audio Klick-Feedback.
- **Interaktiver MagSafe Ladecase Simulator:** Realitätsgetreues Auf- und Zuklappen des Cases per Klick mit pixelgenauer Gehäusenaht, pulsierender Status-LED und originalem Apple Doppelton-Chime.
- **Kapazitiver Schaft-Sensor:** Interaktiver Touch-Lautstärkeregler mit dynamischer LED-Balkenanzeige und Mikrofrequenz-Audio-Feedback.
- **Horizontales GSAP Scroll-Karussell:** Horizontales Scrubbing durch Schlüssel-Innovationen (H2, 3D Audio, MagSafe U1, 30h Akku, Silikontips, IP54).
- **Vollständige Technische Daten:** Präzise Apple Spezifikationen und interaktives Vorbestellungs-Modal.

## 🛠️ Verwendete Technologien

- **HTML5 & Modern Vanilla CSS:** Apple Dark-Luxury Design System, CSS 3D Transforms, Glassmorphism, CSS Grid & Flexbox
- **JavaScript (ES6+):** Modulare, fehlerfreie Architektur
- **GSAP 3.12.5 & ScrollTrigger:** Scroll-Scrubbing, Pinned Sections, Parallax
- **Lenis 1.0.42:** Sanftes, 60fps-optimiertes Trägheitsscrollen
- **Web Audio API:** Prozedurale Synthese von Klicks, Chimes und akustischen Frequenzen ohne externe Audio-Dateien
